## 🎯 БЫСТРЫЕ ЗАДАЧИ

### Добавить новый канал
1. Откройте: src/data/channels.json
2. Добавьте объект канала:
```json
{
  "id": "5",
  "name": { "en": "New Channel", "ru": "Новый канал" },
  "country": "RU",
  "genres": ["News"],
  "url": "https://example.com/stream.m3u8",
  "logo": "/logos/new.png"
}
```
3. Сохраните - фильтры обновятся автоматически!

### Добавить новый язык
1. Создайте файл: src/data/i18n/de.json
2. Скопируйте структуру из en.json
3. Переведите все значения
4. В App.jsx добавьте:
```javascript
import de from "./data/i18n/de.json";
const languages = ["en", "ru", "de"];
const translations = { en, ru, de };
```

### Изменить стили
1. Откройте: src/index.css
2. Измените цвета, размеры, отступы
3. Автоматически перезагружается при сохранении (hot reload)

## ❓ ЧАСТЫЕ ВОПРОСЫ

**Q: Где добавить свои каналы?**
A: src/data/channels.json - просто добавьте объект канала

**Q: Как изменить язык по умолчанию?**
A: В App.jsx измените: const [lang, setLang] = useState("ru");

**Q: Как добавить более сложные фильтры?**
A: В App.jsx измените функцию filtered (используется useMemo)

**Q: Можно ли использовать свой плеер?**
A: Да, замените src/components/Player.jsx своим компонентом

**Q: Как сохранить настройки пользователя?**
A: Используйте localStorage или подключите API сервера
