## МЕСТНОЕ ТЕСТИРОВАНИЕ (ДО РАЗВЕРТЫВАНИЯ)

```bash

```

```bash
npm run build
npm run preview
```

```javascript

window.Telegram?.WebApp   // undefined, если не в Telegram (нормально)

// Проверить инициализацию
```

## СОЗДАНИЕ TELEGRAM БОТА

### 1. Открыть BotFather
Откройте в Telegram: https://t.me/botfather

### 2. Создать новый бот
```
Отправьте: /newbot

BotFather спросит:
  • Имя бота: IPTV Player
  • Username: iptv_player_bot (должен быть уникален)

Вы получите BOT_TOKEN вроде: 123456:ABC-DEF...
```

### 3. Зарегистрировать Mini App
```
Отправьте BotFather: /newapp

Заполните:
  • Bot: выберите созданного бота
  • App Name: IPTV Player
  • Short name: iptv_player
  • Description: IPTV Player with country and genre filters
  • App URL: https://your-domain.com/  (ваш URL)
  • Default admin rights: (оставьте пусто)

BotFather выдаст APP_NAME вроде: iptv_player_bot
```

## РАСПРОСТРАНЁННЫЕ ПРОБЛЕМЫ

### Проблема: "Приложение не загружается"
Решение:
  1. Проверьте консоль на ошибки (F12)
  2. Убедитесь что URL правильный в BotFather
  3. Очистите кэш: Ctrl+Shift+Delete
  4. Перезагрузитесь: Ctrl+R

### Проблема: "Dark mode не работает"
Решение:
  1. Включите темный режим в Telegram Settings
  2. Перезагрузите Mini App
  3. Проверьте класс 'telegram-dark' в консоли

### Проблема: "Видео не воспроизводится"
Решение:
  1. Проверьте что URL потока правильный
  2. Убедитесь что поток живой/доступен
  3. Проверьте консоль на CORS ошибки
  4. Используйте https:// вместо http://

### Проблема: "Вибрация не работает"
Решение:
  1. Вибрация работает только на мобильных устройствах
  2. Убедитесь что браузер поддерживает Vibration API
  3. Проверьте что не отключена в настройках телефона

## ОБНОВЛЕНИЕ MINI APP

Для обновления кода:

1. Обновите код на сервере
2. Очистите кэш CDN (если используется)
3. Пользователи увидят новую версию при следующем открытии
4. Можно добавить версию в App.jsx для отслеживания

```javascript
// В App.jsx
const APP_VERSION = "1.0.1";
console.log("App version:", APP_VERSION);
```

## МОНИТОРИНГ И СТАТИСТИКА

Добавьте отслеживание:

```javascript
// Отправлять статистику на сервер
const logEvent = (event, data) => {
  fetch('/api/analytics', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      event,
      userId: user?.id,
      timestamp: new Date(),
      ...data
    })
  });
};

// Использование
logEvent('channel_selected', { channelId: '123' });
```
